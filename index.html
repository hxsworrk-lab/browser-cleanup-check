Interpretation

One failure, a bounded comparison.

What the comparison checks

An asynchronous onMount callback returns a Promise. This study compares it with a synchronous callback that returns a cleanup function. Both complete their setup before the harness requests unmount.

The report checks real component destruction alongside controlled close() calls. The table and JSON contain observed results from the current run, rather than a saved success result.

The synchronous control is not a complete production fix: if destruction occurs while setup is pending, cleanup can run before the resource has been assigned. That timing is not tested here.

What remains outside this test

  • Real HTTP or SSE traffic, reconnect behavior, and network teardown.
  • Memory retention or a measured memory leak.
  • Unmount while asynchronous setup is still pending.
  • Production-application acceptance or a delivered client repair.
